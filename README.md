# 🛍️ MarkMais — Sistema de Gestão de Estoque

Sistema interativo desenvolvido em **Python** para o controle automatizado de inventário da **MarkMais**. O software permite gerenciar o catálogo de peças de vestuário de forma dinâmica, sincronizando produtos e preços, realizando cadastros, exclusões inteligentes e gerando relatórios consolidados ao final de cada sessão.

---

## 🚀 Funcionalidades do Sistema

1. **Visualização em Tempo Real:** Mostra a listagem completa de produtos e valores ativos nas prateleiras da MarkMais.
2. **Cadastro Dinâmico:** Permite adicionar novas peças de roupa e seus respectivos preços diretamente pelo terminal.
3. **Remoção do Último Item:** Utiliza a lógica de pilha (`.pop()`) para apagar o último item e valor cadastrado no estoque de forma segura.
4. **Remoção por Nome:** Faz a busca exata de um item (`in produtos`) e localiza seu índice (`.index()`) para removê-lo mantendo a sincronia perfeita das listas.
5. **Relatório Consolidado & Ciclo de Reinício:** Exibe um resumo detalhado de tudo o que estava no estoque, o que foi inserido e o que foi apagado durante a sessão, dando a opção de reiniciar a operação do zero ou finalizar o programa.
